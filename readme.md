Paham, jadi web sekarang punya 4 bagian:

Panel alat (yang udah ada) — live bb/tb + QR, murni readout, nggak berubah.
Tabel data Ortu — daftar semua akun ortu, tiap baris nunjukin: jumlah balita yang dia punya, berapa yang sudah ditimbang (bulan ini) vs belum. Ini kayak dashboard monitoring buat kader ngecek siapa aja yang belum dateng nimbang.
Menu Grafik (rata-rata pertumbuhan) — bukan grafik per-bayi kayak di app mobile, tapi agregat/rata-rata dari semua balita (misal: rata-rata bb per usia bulan, dibandingin sama kurva median Permenkes) — buat liat tren pertumbuhan populasi balita di posyandu itu secara keseluruhan.
Menu Rekap/Cetak PDF per-ortu — laporan yang bisa di-generate per akun ortu, isinya: histori pengukuran tiap balita yang dia punya + catatan kader untuk masing-masing balita itu.
